# FocusMinder

A Pomodoro-style focus timer for Mac. Runs automatic work/break cycles, tracks daily focus minutes toward a goal, and builds consistency with streaks — all from your menu bar.

---

## Download

👉 **[Download the latest release](../../releases/latest)**

Click the link above → download `FocusMinder.dmg`

---

## Installation

1. Open `FocusMinder.dmg`
2. Drag `FocusMinder.app` to your **Applications** folder
3. Launch FocusMinder from Applications

## Features

- Tutorial for first-time app users to better understand what it does
- Automatic work/break Pomodoro cycles
- Notifications when phases transition
- Daily focus minutes tracked toward a goal
- Streak tracking to build consistency
- Lives entirely in the menu bar — no dock icon, no clutter

---

## Privacy

FocusMinder collects no data whatsoever.

- No analytics
- No crash reporting  
- No network requests — the app never connects to the internet
- All data (session history, streaks) is stored locally on your device only
- No pesky notifications other than core app functions

---

## Requirements

- macOS 26 Tahoe or later
- Apple Silicon or Intel Mac
